# 有没有人因为没有宫缩剖腹产打,剖腹产后打宫缩针打哪里啊

> 更新时间：2026-09-17 (UTC+8)

现在很多人之所以会选择剖腹产是因为能减少很多的疼痛，但有些分娩的疼痛是没办法避免的，比如说产后的宫缩痛，是很多妈妈都要经历的。那么，有没有人因为没有宫缩剖腹产打呢?请跟着小编一起来看看隐藏在剖腹产之中的一些小秘密吧!
有没有人因为没有宫缩剖腹产打
　　没有。

　　临产后如果宫缩弱，那可以静点缩宫素加强宫缩。静点缩宫素出现的疼痛跟自然临产之后的宫缩疼痛是一样的。分娩之后也会静点缩宫素来促进宫缩、降低产后出血的几率，这个时候宫缩就没有分娩前那么疼了。女性在分娩之前就应该做好心理准备，分娩的宫缩痛是比较痛的，要耐受这种宫缩才能顺利分娩。现在很多医院都在开展无痛分娩，这就大大降低了孕妇的疼痛，会提高顺产的比例。

　　打缩宫素主要是刺激子宫平滑肌收缩，导致宫颈口扩张。打缩宫素多久起作用是因人而异的。而且每个人对缩宫素的敏感性不一样。打缩宫素起作用快慢，也与宫颈条件有关。如果宫颈条件好，缩宫素起效就快一些。一般情况下，打缩宫素素30-60分钟可以起作用，而且打缩宫素可以刺激乳房的平滑肌收缩，帮助乳汁从乳房中排出，但不会增加乳房的乳汁分泌。

　　剖腹产可以让产妇避免产前阵痛，但是麻药药效过了之后，还是要忍受伤口愈合和宫缩的痛。因此这种方式虽然可以将我们分娩的痛苦降到最低，但产后会比顺产疼很多。相信大家都知道，生育过后子宫会出现收缩，剖腹产过后女性朋友们会明显感觉到宫缩的疼痛。
剖腹产后不打宫缩素
　　一般情况下，剖腹产手术以后医生都会给你注射缩宫素用来帮助子宫收缩。刨腹产手术以后使用收缩子宫的药物是必须的，这样为了防止产后出血。如果注射这个药物期间有肚子疼痛情况，说明子宫收缩不良。建议到医院进行咨询。宫缩针的作用有很多，所以要根据不同的情况具体分析，并且每个人的体质都是不一样的，所以对于宫缩针的反应时间也是存在差异的。宫缩针的作用是促进子宫收缩，促进子宫内异物排出。注射后会有腹痛、下体分泌物增多或出血的症状。具体情况时有个体差异的，建议做B超复查。打完收缩子宫的药以后会帮助排出宫腔内的残留物，所以恶露增多属于正常，要注意个人卫生。

　　一般的产妇需要打三天的收宫素，身体比较敏感的产妇，可能需要打五天的缩宫素。在医院打缩宫素，医生会根据你子宫恢复的情况来决定。因为产妇进行剖腹产，子宫体会有创口，有创口子宫就会大量的出血。有一些体质比较敏感的，子宫出血量非常的大，这个时候我们就必须要应用缩宫素，给产妇缩宫素可以促进子宫的修复还可以减少产妇的出血量。
