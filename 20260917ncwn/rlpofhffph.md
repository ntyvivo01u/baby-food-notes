# 登革热可能并发哪些疾病？

> 更新时间：2026-09-17 (UTC+8)

我相信你最害怕的疾病是传染病。事实上，我们不知道我们最应该害怕的是传染病的并发症。我们以前介绍过登革热的疾病预防。仅仅预防是不够的。我们还需要了解登革热的并发症。我希望你能更加关注登革热。

 1.急性血管溶血 最常见，发病率约为1％，红细胞多发生在红细胞中-6-磷酸脱氢酶缺陷患者。主要表现为酱油排尿、贫血、气短、心率加快、尿标本检查无或只有少量红细胞，潜血试验呈强阳性。值得注意的是，当急性血管溶血发生时，血液中G6PD含量可在正常范围内，一个月后才出现含量缺陷。这是因为急性血管溶血时，血液中G6PD缺陷的成熟和衰老的红细胞已经裂解，剩下的是G6PD含量相对较高的年轻红细胞在发育成熟和衰老时逐渐出现G6PD缺陷所致。

 2.精神异常 个别患者可并发感染性精神异常，尤其是有精神病家族史的患者。

 3.心肌炎 严重病例可发生心肌炎，主要表现为心跳、气短、心率增快、心律失常。

 4.肝功能损伤 轻度肝功能损伤常见，主要表现为肝轻度肿大、边缘锐利、质软、肝功能检查ALT、AST 和γ-谷氨酰转肽酶(γ-GT)等待上升。总胆红素可发生在严重病例中。(TBIL)肝肾综合征甚至升高。

 5.登革出血热患者常见尿毒症 ，大量出血或急性血管溶血可促进尿毒症的发生。

 6.急性呼吸窘迫综合征(ARDS)可见于重度和登革出血热患者，表现为呼吸急促、窘迫、易怒、发绀、肺干湿。动脉血气分析，动脉血氧分压(Pa02)8.0kPa(60mmHg)，早期动脉血二氧化碳分压(PaC02)常4.7kPa(35mmHg)，晚期PaCO2则可6.0kPa(45mmHg)。

 7.颅内高压、急性播散性脑脊髓炎、感染性多发性神经根炎、眼葡萄膜炎等可能发生的其他并发症。

 我们将介绍登革热的并发症。任何疾病都有并发症。因此，我们希望我们关注疾病的并发症。许多人没有被这些疾病击倒，而是被这些疾病的并发症所实现。因此，我们不能忽视生活中疾病的并发症。
